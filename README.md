### 📖 Overview
TeamBox™ is a mod for Rejuvenation that allows the user to store their team configuration through a dedicated menu, in an easy and quick way.

You can store your team's entire loadout (that is, Ability, Nature, Item, EV, and Moves) in a box, and when desired, load it back up exactly as you left it, while your previous party will be sent to the PC. In addition, each of your save files will have its own set of boxes.

Effectively, this means you can store a Doubles or Singles configuration, a Sun or Rain, etc, and swap between them easily. How quaint.

#
### 🔧 Installation
1) Go to [the Releases page](https://github.com/qploop/TeamBox/releases)
       
2) Download TeamBox.zip

3) Extract the file

4) Place extracted 'Mods' folder inside the 'patch' folder, located in the same folder as the executable

5) Turn autosaving on
