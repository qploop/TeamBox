### OVERVIEW
TeamBox™ is a mod for Rejuvenation that allows the user to store their team configuration through a dedicated menu in an easy and quick way.

You can store your team's entire loadout (that is, Ability, Nature, Item, EV, and Moves) in a box, and when desired, load it back up exactly as you left it, while your previous party will be sent to the PC.

Effectively, this means you can store a Doubles or Singles configuration, Sun or Rain, etc, and swap between them easily. How quaint.

#
### 🔧 Installation
1) [Go to the releases page](https://github.com/qploop/TeamBox/releases)  <br>
       
2) Download TeamBox.zip

3) Extract the file

4) Place extracted 'Mods' folder in the 'patch' folder next the Rejuvenation executable file

5) Turn autosaves on, this is a new release and may contain unanticipated bugs.
